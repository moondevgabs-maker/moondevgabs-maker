Olá! Sou a **Gabbs**, estudante de **Ciência de Dados e Desenvolvimento de Sistemas**, com alma de feiticeira e uma curiosidade que insiste em me fazer abrir mais uma aba e perguntar: *“mas como isso funciona?”* 🔮

Minha jornada em tecnologia começou pelo **Front-End**, onde tive contato com **HTML, CSS, JavaScript, Git e UX/UI**. Foi meu primeiro portal para esse universo e continua fazendo parte da minha história, mas, no caminho, descobri que minha curiosidade estava me puxando para outros territórios.

Hoje, meus estudos estão direcionados principalmente para **Dados, Python, SQL, Java, AWS/Cloud e Inteligência Artificial**, enquanto continuo construindo minha base em desenvolvimento e entendendo, projeto por projeto, onde cada tecnologia se encaixa.

**Ainda estou aprendendo. E este GitHub também é o registro dessa evolução.**

Aqui você vai encontrar desde projetos e desafios do começo da minha jornada até aquilo que estou construindo agora. Alguns são simples, outros já exigiram alguns neurônios a mais — e alguns quase levaram todos eles embora. 😂

Além dos códigos, acredito muito em **tecnologia construída em comunidade**. Compartilhar conhecimento, aprender com outras pessoas e tornar esse universo um pouco menos assustador para quem também está começando faz parte do que quero construir por aqui.

#### 🔮 Assistência Técnica de Eletrônicos

> **Java • Programação Orientada a Objetos • ArrayList • Relacionamento entre Classes**

Sistema desenvolvido durante meus estudos de **Desenvolvimento de Sistemas** para representar o fluxo de atendimento de uma assistência técnica de eletrônicos.

O projeto trabalha com clientes, equipamentos, técnicos, diagnósticos, serviços e ordens de serviço, aplicando conceitos de **Programação Orientada a Objetos** na construção e relacionamento das classes.

**Principais conceitos praticados:**

- Encapsulamento
- Classes e objetos
- Construtores
- Métodos
- Relacionamento entre classes
- `ArrayList`
- Organização de responsabilidades
- Fluxo de uma ordem de serviço
