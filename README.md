### 🜁 Sobre Mim — *Quem Habita Esta Sombra*

Olá! Sou a **Gabbs**, estudante de **Ciência de Dados e Desenvolvimento de Sistemas**, curiosa por natureza e oficialmente incapaz de aceitar um *“é assim que funciona”* sem perguntar:

> *“Tá... mas por quê?”* 👀

Minha jornada em tecnologia começou pelo **Front-End** e, no caminho, foi ganhando novos territórios.

Hoje meus estudos estão voltados principalmente para **Dados, Python, SQL, Java, Banco de Dados, AWS/Cloud e Inteligência Artificial**, enquanto continuo construindo minha base em desenvolvimento.

Não estou tentando parecer uma feiticeira nível 99 que domina todos os grimórios. 😌

**Ainda estou aprendendo. E este GitHub também é o registro dessa evolução.**
